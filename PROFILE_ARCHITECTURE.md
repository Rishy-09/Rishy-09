# Profile Architecture

This GitHub profile is intentionally built as a hybrid system combining custom visuals, generated activity data, and GitHub-compatible Markdown.

## Components

- **Custom SVG panels** — locally stored SVG assets used for visual design and lightweight animation.
- **GitHub summary cards** — generated from real GitHub activity data.
- **Markdown / HTML layout** — provides the structure rendered by GitHub.

## Automation

Activity cards are generated by:

```text
.github/workflows/profile-summary-cards.yml
```

The workflow runs automatically on a schedule and can also be triggered manually.

Generated cards are stored in:

```text
profile-summary-card-output/
```

## Profile Validation

Basic profile integrity is checked by:

```text
.github/workflows/profile-check.yml
```

This verifies that the README and required visual assets are present.

## Rendering

Custom SVG panels use SVG/CSS features and do not execute JavaScript.

`README.md` is the deployed profile README displayed on the GitHub profile.
