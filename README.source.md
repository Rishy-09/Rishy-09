# Rishy-09 profile source

This profile is intentionally built as a hybrid system:

- animated local SVGs for custom design and motion
- generated GitHub summary cards for real activity stats
- Markdown/HTML layout for GitHub compatibility

The SVG panels are static files with CSS/SVG animation. They do not run JavaScript.
The activity cards are generated by `.github/workflows/profile-summary-cards.yml` and update when the workflow runs.

Use `README.md` as the deployed profile README.
